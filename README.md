# Grupo Proença — site institucional

Site responsivo do Grupo Proença para divulgar o desenvolvimento de **sites, aplicativos e automações** voltados a pequenos negócios.

## Estrutura

- `index.html`: página principal, CSS e JavaScript do site.
- `assets/logo.png`: logotipo do Grupo Proença.

## Publicação na Netlify

1. Entre em https://app.netlify.com/ e faça login.
2. Clique em **Add new project** → **Import an existing project**.
3. Escolha **GitHub** e autorize o acesso ao repositório, se solicitado.
4. Selecione `thecalebe/grupo-proenca-site.` (observe o ponto final no nome).
5. Configure **Branch to deploy** como `main`; deixe **Build command** vazio e indique a raiz do repositório como diretório de publicação (`.`).
6. Clique em **Deploy**. A Netlify fornecerá uma URL HTTPS pública.
7. Em **Domain management**, é possível alterar o subdomínio gratuito para um nome disponível.

A página é HTML/CSS/JS estático e não requer Node.js, banco de dados, chaves de API ou processo de build. Atualizações no GitHub serão publicadas automaticamente quando o projeto estiver conectado à Netlify.
